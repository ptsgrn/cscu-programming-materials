# Security — Frequently Asked Questions

Written by the Security team for new joiners. This page is orientation, not policy. SEC-002 is the policy.

**Why do I need a hardware key? My phone has an authenticator app.**
Because phishing works against app codes and does not work against a hardware key bound to the origin. This is not negotiable for employees.

**I lost my security key.**
Tell the service desk immediately. They will revoke it and issue a temporary path with a manager present. Do not borrow a colleague's key; that is a reportable incident on both sides.

**Can I install software on my laptop?**
Anything in the self-service catalogue, yes. Anything else goes through a request, mainly so we know what is running when a vulnerability is announced.

**Why did my access to a system disappear?**
Probably because you had not used it in a while and the automatic review removed it. Ask for it back; it takes minutes.

**Can I use a personal cloud drive for work files?**
No. Not for convenience, not temporarily, not for a file you will delete afterwards.

**Someone emailed asking me to confirm my login. What do I do?**
Do not reply. Forward it to the security channel. If you already clicked, say so — quickly and without embarrassment. Speed matters far more than the mistake did.

**Is there a bug bounty?**
For our customer-facing API, yes, run through a third party. Internal systems are out of scope.

**Where do secrets go?**
Never in a repository, a ticket, or a chat message. There is a vault, and it is the only answer.
